# 🛍️ ShopiZo - Modern E-Commerce Website

ShopiZo is a modern and responsive e-commerce shopping website built using HTML, CSS, JavaScript, and Bootstrap.

The project includes dynamic product pages, shopping cart functionality, payment page UI, responsive layouts, attractive product cards, and modern ecommerce design.

---

# 🚀 Features

✅ Responsive Modern UI
✅ Dynamic Product Pages
✅ Add To Cart System
✅ Cart Count Badge
✅ Payment Checkout Page
✅ Product Image Gallery
✅ Recommended Products Section
✅ Bootstrap Integration
✅ Stylish Footer & Navbar
✅ Mobile Responsive Design
✅ Hover Animations & Modern Effects

---
